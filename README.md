# IT Internship Portfolio

A responsive, clean-professional portfolio website for a Computer Science student.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive styles
- `script.js` — mobile navigation and current year

## Before publishing
1. Replace `[Your Full Name]`, `[Your Name]`, and `[YN]`.
2. Replace `[Expected Graduation Year]`.
3. Replace `[YourEmail@example.com]`, `[Your LinkedIn URL]`, and `[Your GitHub URL]` with real details. If a profile isn't ready, remove its link instead of leaving a placeholder.
4. Check the skills list and project descriptions for accuracy.
5. Replace the illustrative CSS project mockups with genuine screenshots when you have them. They are explicitly labelled as illustrative.
6. Test all links and preview on mobile.

## Publish with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to deploy. Your site will normally be at `https://yourusername.github.io/`.

If using a different repository name, enable Pages in its settings and use the project URL GitHub provides.
